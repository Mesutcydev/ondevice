# ondevice.fun

Promotional site for the **OnDevice** apps: free, open-source iPhone apps that
run AI on the device. One page per locale: English (`/`), Turkish (`/tr/`),
Simplified Chinese (`/zh/`).

| Code | App | Status | Needs |
| --- | --- | --- | --- |
| OD—01 | **OnDevice Max** — new interface, all-in-one studio | coming soon | iOS 27 |
| OD—02 | **OnDevice Core** — same engine as Max, classic Studio UI ([repo](https://github.com/Mesutcydev/ondevice-core)) | available | iOS 27 |
| OD—03 | **OnDevice LAS** — local OpenAI/Anthropic/Ollama-compatible API server | beta | iOS 18 |
| OD—04 | **OnDevice Image Generation** (app name "iOS Image Generation") — Stable Diffusion / SDXL | coming soon | iOS 26 |

All apps are sideloaded (IPA + AltStore / SideStore / ForgeSign), not App Store.

## Design

Black stage, paper spec sheets, dot-matrix display type. References: Nothing
(dots, mono labels, red accent), Teenage Engineering (paper background, product
codes, one colour per product), Moonshot (big quiet hero).

- Dot-matrix headlines are real, selectable text masked into a dot grid
  (`.dots` in `site.css`); no display font download.
- Accent `#ff4a1c`; product colours Max red, Core green, LAS blue, Image violet.
- "Live" motion: pulsing status dot, floating phone fan, model ticker,
  auto-advancing Max showcase tabs. All of it stops under `prefers-reduced-motion`.
- Screenshots are iPhone Simulator captures (Max via `QA/NativeUI` review host
  fixtures, Image Generation via onboarding), stored as 660px WebP in
  `assets/shots/`.

## Layout

```
public/
  index.html        English — the source page
  tr/ zh/           generated by i18n.py, do not edit by hand
  llms.txt          agent-readable summary: apps, downloads, install, API routes
  404.html  robots.txt  sitemap.xml  _headers  _redirects
  assets/shots/     app screenshots (WebP)
  assets/icons/     app icons (WebP)
  assets/og-*.png   share cards per locale
  shell/site.css    design system
  shell/site.js     menu, reveal, showcase tabs, copy button
i18n.py             builds tr/ and zh/ from the English page
wrangler.jsonc      Worker config: assets dir + custom domains
```

## Editing

1. Edit `public/index.html`.
2. Run `python3 i18n.py`. It fails and lists every English string that no
   longer has a translation; add those pairs to `TR` and `ZH`, then rerun.
3. Bump `?v=` on `site.css` / `site.js` when either changes.

SEO and agents: each page carries JSON-LD (`Organization`, `WebSite`, an
`ItemList` of `SoftwareApplication`, and a `FAQPage` matching the visible FAQ),
hreflang alternates and per-locale share cards. `llms.txt` is linked from every
page head and from `robots.txt`.

No bundler, no `package.json`. Wrangler runs through `npx` in Workers Builds;
pushing to `main` deploys. Custom domains `ondevice.fun` and `www.ondevice.fun`
are declared in `wrangler.jsonc`.
