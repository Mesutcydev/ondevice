Token AI

Download a compatible AI model and chat offline on your iPhone. Token AI also brings together camera Lens, voice conversations, Image Studio, and a local API server. Requires iOS 27 or later.

What you can do

  • Chat with a local model. Write, explore ideas, and attach photos or files. Available model families include Qwen, Gemma, and Llama.
  • Use Lens or voice. Ask about an image with a compatible vision model or download the speech components for local voice conversations.
  • Generate images. Install a compatible image model to create images in Image Studio. A parental PIN can restrict generation.
  • Connect your tools. Serve a loaded model to compatible clients on a trusted local network using the authenticated Local API Server.

iPhone requirements

Token AI is listed as Token: Local AI Studio on the App Store. It was previously called OnDevice Max. The app requires iOS 27 or later. Model files are separate downloads, and model compatibility depends on memory and storage. Start with a small chat model using the offline LLM setup guide.

If your iPhone runs iOS 18 through iOS 26, try OnDevice Local AI Studio.

Local models and optional connections

Local chat processes prompts on the iPhone, with no OnDevice account required. Model downloads and enabled features such as external API providers, web tools, iCloud sync, and paired Mac tools use their respective network services. See the Token AI privacy policy and support page for details.
