OD—03 / OnDevice LAS

Run a local LLM API on iPhone

OnDevice LAS serves a model running on your iPhone to your tools over a trusted local network. The dedicated server build requires iOS 18 or later and is distributed as a sideload IPA.

Install the server

Download the OnDevice LAS 3.2.6 (146) IPA above (24.8 MB). Sign and install it with a compatible sideloading tool. The increased-memory-limit entitlement may be needed for larger models. Token AI includes a local API server and is available through the App Store.

Connect from your Mac or another LAN client

  1. Download and load a compatible chat model in OnDevice LAS.
  2. Enable the Local API Server. Allow Local Network access and keep the app in the foreground.
  3. On the same trusted network, copy the address and bearer key shown in the app. Use those values in your client.
curl "http://PHONE-IP:11434/v1/models" \
  -H "Authorization: Bearer $ONDEVICE_KEY"

Use the returned model ID in your chat request. The server stops when the app goes to the background. The LAS build uses HTTP on the LAN, so keep the bearer key private and avoid port forwarding or public exposure.

Supported API routes

  • OpenAI-compatible: GET /v1/models, POST /v1/chat/completions, and POST /v1/responses.
  • Anthropic-compatible: POST /v1/messages.
  • Ollama-compatible: model, chat, and generation routes under /api.

See the integration guide for request examples and route limits.
