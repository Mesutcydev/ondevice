Help with
Local AI Studio.

Contact the project, report unsafe AI output, or resolve common problems. OnDevice Local AI Studio requires iOS 18 or later. No OnDevice account is needed.

Contact support

Email mesutcydev@gmail.com with your iPhone model, iOS version, app version, the model you were using and the steps that led to the problem. You can also open an issue in the public source repository; a GitHub account is needed for that.

Email supportOpen a support issue

GitHub issues are public. Remove API keys, access tokens, pairing credentials, private conversations, photos and documents before posting or emailing.

For a security vulnerability, follow the repository’s security reporting instructions instead of posting sensitive details publicly. For privacy questions, read the privacy policy.

Report unsafe or offensive AI output

If a response is unsafe, offensive or inappropriate, email mesutcydev@gmail.com with the app version and a short description of what happened. You do not need to send private text. Recent versions of the app also have a Report action: press and hold an AI response and tap it to open this page.

Reports are reviewed and used to improve the safeguards. Conversations are stored only on your device, so they cannot be seen or removed from here. Image prompts and outputs are checked on the device, and a parent can restrict image generation with a PIN. These checks can make mistakes, and downloaded models differ in how well they follow safety instructions.

Downloads and storage

If a download stops, check your connection and free storage, then retry from the model list. The download screen shows each model’s size before you start. Use the model library to remove models you no longer need; a deleted model must be downloaded again before use.

Never share your Hugging Face token in an email or issue.

Models and generation

Which models run, and how fast, depends on your iPhone’s memory, storage and temperature. A model that is too large for your device is declined with a message instead of closing the app. If a model will not load, try a smaller one and close other apps. If the iPhone gets warm, let it cool and try again.

AI output can be inaccurate. Review it before using or sharing it.

Camera, voice and photos

Open the feature you want to use and allow the permission when iOS asks. If you denied camera, microphone or speech recognition earlier, change it in iOS Settings. Speech recognition uses on-device recognition only; if it is unavailable the app declines instead of sending audio to a server.

Calendar and Reminders

In versions that include them, the assistant can read upcoming calendar events, add an event, or add a reminder. Each request asks for your approval in the chat and shows exactly what will be read or written, then iOS asks for its own permission. You can decline, and you can turn access off in iOS Settings at any time. Voice conversations cannot use these tools.

Local API and web search

The Local API is optional and off until you turn it on. It requires an API key, uses HTTPS, is meant for networks you trust, and stops when the app goes to the background. Do not expose it to the internet. See the integration guide.

Web search is optional. A permission sheet shows the provider and the exact query before anything is sent. Providers receive the request under their own privacy terms.

Your data

Open Settings in the app and choose Wipe all on-device data to clear local conversations, models, caches and saved credentials. It does not delete iCloud copies, exported files or records held by a web search provider; the privacy policy explains how to remove those.
