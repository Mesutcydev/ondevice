OnDevice Local AI Studio

Run downloaded AI models on iPhone with iOS 18 or later. Use the original Studio interface for local chat, code, camera OCR, voice conversations, and image generation.

What you can do

  • Chat and work with code. Run a compatible model on the device, save snippets, or export a conversation.
  • Read text with the camera. Built-in OCR works without a vision-model download. Image questions require a compatible vision model.
  • Talk or create images. Voice can use local Apple speech where supported, with optional downloadable neural voices. Image generation uses a separate model.

iPhone requirements

Look for OnDevice: Local AI Studio in the App Store. It requires iOS 18 or later. Choose a model that fits the phone’s memory and allow space for the downloaded files. Follow the offline LLM setup guide for a small first model and an airplane-mode check.

If you use iOS 27 and want the newer interface, compare Token AI.

Local models and optional connections

Downloaded models run on the device. Model discovery and downloads use the network, as do optional features such as web search, iCloud sync, the Local API, and paired Mac tools. A web provider may receive queries or content you send to it. See the Studio privacy policy and the App Store privacy label.

Source code and support

Read the source repository or open a support issue. Include the app version, iPhone model, iOS version, and model name. Remove private content and credentials first.
