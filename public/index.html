For developers

Your iPhone
is the server.

OnDevice LAS, and the API server in Max and Core, answer standard requests on your local network. Point Cursor, scripts or agents at your phone and keep the model private.

# placeholders, not live values
curl -N http://PHONE-IP:11434/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -d '{"model":"MODEL-ID","stream":true,
       "messages":[{"role":"user","content":"Hello"}]}'
  • OpenAI/v1/models · /v1/chat/completions · /v1/responses
  • Anthropic/v1/messages
  • Ollamamodel, chat and generate routes under /api

Bearer-authenticated HTTP for a network you trust. It stops when iOS backgrounds the app; don't port-forward it. Integration guide ↗

Install

Sideload in
three steps.

The apps aren't on the App Store yet. You install the IPA yourself and sign it with your own Apple ID. It takes about five minutes.

01

Download the IPA

Pick an app in the lineup and download its IPA from GitHub Releases. The apps ship without model weights.

02

Sign and install

Open the IPA with a signer on your Mac or iPhone. Any of these work:

AltStore ↗SideStore ↗ForgeSign ↗
03

Get a model, go offline

Open the app, download a model that fits your phone and load it. Then switch on airplane mode and keep going.

Keep the memory keys

Make sure your signer keeps the increased-memory-limit and extended-virtual-addressing entitlements. Without them iOS caps the app's memory and large models are stopped while loading.

FAQ

Good
questions.

Still stuck? Open an issue and we'll help.

How do I run an LLM on my iPhone offline?

Install OnDevice Max or OnDevice Core (iOS 27), download a model once over Wi-Fi, for example Qwen 3 4B, then load it. From then on chat works with no connection at all, including in airplane mode.

Are the OnDevice apps on the App Store?

Not at the moment. They are distributed as sideloadable IPA files on GitHub Releases. You sign and install them on your own device with AltStore, SideStore or ForgeSign. The source code is public under the MIT licence.

What is the difference between Max and Core?

They share the same on-device engine and features. Max has the new, calmer interface and is the newest build; Core keeps the original Studio interface. OnDevice LAS turns an iPhone into a local API server, and OnDevice Image Generation is for making pictures.

Which iPhones are supported?

OnDevice LAS needs iOS 18 or later, OnDevice Image Generation needs iOS 26, and OnDevice Core and Max need iOS 27. Bigger models need more memory; the model library checks whether a model fits your device before you download it.

Does anything I type leave my phone?

Not by default. Inference runs on the device and there is no account, analytics or telemetry. The network is used only for model downloads you start and optional features you switch on, such as web access, Apple Private Cloud Compute or a paired Mac.

Can I generate images on an iPhone without the internet?

Yes. OnDevice Image Generation runs Stable Diffusion 1.5, 2.1, SDXL and SDXL Turbo locally with MLX and Core ML. OnDevice Max and Core also include an image studio.

Can my iPhone act as an OpenAI-compatible API?

Yes. OnDevice LAS serves OpenAI-, Anthropic- and Ollama-compatible routes on your local network behind a bearer key. It is meant for a network you trust and stops when iOS sends the app to the background.

Is OnDevice free and open source?

Yes. Original code is MIT licensed, with no account and no subscription. Model weights are downloaded separately and keep their own licences.
