How to Run a Local LLM on iPhone Offline

Install an app, download a compatible model once over Wi-Fi, and then check that local chat works with the phone disconnected.

On this page

  • 1. Choose the app for your iOS version
  • 2. Download a small chat model
  • 3. Verify chat in airplane mode
  • If a model will not load

1. Choose the app for your iOS version

  • iOS 27 or later: Token AI offers the newer interface with chat, Lens, voice, and Image Studio. Download Token AI.
  • iOS 18 or later: OnDevice Local AI Studio offers the original interface and works on earlier iOS versions. Download Local AI Studio.

These are the App Store OS requirements. Model fit also depends on the iPhone’s available memory, free storage, and temperature. In Settings → General → About, check your model name and iOS version. The app’s model picker can help you choose a compatible download.

2. Download a small chat model

  1. Connect to Wi-Fi. In the app, open Models and then Discover.
  2. Look for Qwen3-0.6B, the 4-bit MLX chat model. The app catalog estimates about 400 MB for the download. On supported iOS 27 devices, the Core AI picker also lists Qwen3 0.6B · Official iOS, about 456 MB.
  3. Check the size and device fit shown in the app, then download the model. Allow additional storage for preparation and keep the app open until the download finishes.
  4. Open Assistant, select the downloaded local model, and send a short test message.

Download size and memory use are different. Start with the smallest compatible model and move up after you’ve tried it. The Qwen3 MLX model card describes the 4-bit variant.

3. Verify chat in airplane mode

  1. Keep the downloaded local model selected and start a new chat.
  2. Turn on Airplane Mode and check that Wi-Fi is off. iOS can remember that you previously left Wi-Fi on in Airplane Mode.
  3. Send a new prompt such as “Give me three ideas for a rainy afternoon.” Check that the answer streams while the phone is offline.

Local chat can run with the downloaded model while disconnected. Model downloads, web search, iCloud sync, and remote model providers need connectivity. Camera, image generation, and voice may need their own compatible downloads.

If a model will not load

Confirm that the download finished and that a local model is selected. Free storage, try a smaller model, unload other active models, or let the iPhone cool before retrying. For a reproducible report, note the iPhone model, iOS and app versions, the model name, and the step that failed. See Token AI troubleshooting or Local AI Studio support.
