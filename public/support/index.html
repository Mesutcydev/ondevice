Help with
OnDevice Max.

Start with a compatible model, resolve common problems, or contact the project. OnDevice Max requires iOS 27 or later. No OnDevice account is needed.

Contact support

For help or a reproducible bug, open an issue in the OnDevice Max source repository. Include your iPhone model, iOS version, app version and build, the model name, and the steps that led to the problem.

Open a support issueBrowse existing issues

GitHub issues are public. Remove API keys, access tokens, pairing credentials, private conversations, photos and documents before posting. A GitHub account is needed to create an issue.

For a security vulnerability, follow the repository’s security reporting instructions instead of posting sensitive details publicly. For privacy questions, read the privacy policy and use the support route above without including private data.

Get started

  1. Open the leading menu and choose Models.
  2. Choose Discover, then a compatible model. A small chat example is Qwen3 0.6B Official iOS.
  3. Download the model while connected to the internet. Model files are separate from the app.
  4. Select the downloaded model for Assistant, start a conversation and send a message.

Once a compatible local model is downloaded and loaded, local chat can work offline. Lens, voice and Image Studio need their own compatible models or system capabilities. Optional web tools and iCloud sync still need a connection.

Downloads and storage

If a download stops, check your connection and free storage, then retry from Models. Leave room for the downloaded files and any preparation the model requires; the download size alone may not be the full storage requirement.

Use the model library to remove packs you no longer need. A deleted model must be downloaded again before use. Never share your Hugging Face token in a support issue.

Models and generation

If a model will not load, try a smaller compatible model and unload other active work. The app can refuse or stop work because of memory pressure or device temperature. Let the iPhone cool and retry; repeated retries do not make an oversized model fit.

Image Studio requires a supported image model, downloaded separately. Compatibility and speed vary with the model and your iPhone. AI output can be inaccurate; review it before using or sharing it.

Voice and camera

Open the feature you want to use and allow the relevant permission when iOS asks. If you previously denied camera, microphone or speech recognition access, change it in iOS Settings for OnDevice Max.

Choose the appropriate vision or voice model where required. If a feature stops responding, end the session, let your iPhone cool down and try again with a smaller supported model.

Local API and web tools

Enable the Local API Server only on a network you trust. Use the address and bearer key shown in the app. Keep the iPhone and client on the same local network and allow iOS local-network access. The server stops when the app backgrounds.

Do not expose or port-forward the server to the internet. Keep its bearer key and paired-Mac credentials private. See the integration guide for supported routes and their limits.

Web tools are optional. Check the provider and credentials you configured if a search fails. Providers receive the request under their own privacy terms; disable web access if you want to keep the workflow local.

Data and parental controls

Settings contains controls for clearing local content and credentials, and for optional iCloud conversation sync. Clearing local data does not automatically remove exported files or copies held by another app or provider. Use the cloud controls for the iCloud copy.

A parent can set a PIN to restrict image generation. Changing or removing the restriction requires that PIN. Clearing app data intentionally preserves parental controls, and Keychain records may survive uninstall. The project cannot retrieve a parent PIN or access conversations stored on your iPhone.

Read the privacy policy for storage, retention and optional network behavior.
