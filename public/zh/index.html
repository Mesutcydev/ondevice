04 / API

接上你的工具。

On Device: LAS 在你的局域网内应答兼容 OpenAI、Anthropic 与 Ollama 的请求，背后是你自己掌控的 bearer key。

  • OpenAI/v1/models, /v1/chat/completions, /v1/responses
  • Anthropic/v1/messages
  • Ollamamodel, chat and generation routes under /api
# 示例请求——占位符，非真实值
curl -N http://PHONE-IP:11434/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -d '{"model":"MODEL-ID","stream":true,
       "messages":[{"role":"user","content":"…"}]}'

边界：监听只服务你的局域网，iOS 将应用切到后台时即停止。安装后请轮换 key；不要做端口转发。

从下载到模型驻留。

两个版本都是同样的三步。这里没有一键完成，这是实话：侧载构建需要你的证书。

01获取

下载你需要的版本

从版本页取 IPA。两者都是面向重签工具的 ad-hoc 签名产物——不是 App Store 安装。

02安装

安装并重签

使用 AltStore / AltServer、SideStore，或在设备上用 ForgeSign 签名。确认重签后内存 entitlement 仍在：缺少 increased-memory-limit 与 extended-virtual-addressing 时，iOS 会压低进程上限，大模型不是降级运行，而是加载时直接被杀。

03运行

载入模型并让它驻留

仓库不含权重。在设备上导入 GGUF 或下载 MLX 模型，然后载入。LAS 中请轮换 bearer key，并把客户端指向应用显示的局域网地址。

侧载，而非 App Store。这些 IPA 是面向重签工具的 ad-hoc 签名产物——请用 AltStore、SideStore 或设备上的 ForgeSign 安装。仓库是源码分发的正式地址；目前没有 App Store 安装包。

它不做什么。

把话说清楚，因为信任就是产品本身。

不把自己暴露到公网

本地 API 是 bearer 鉴权的明文 HTTP，只面向你能掌控的网络。不要做端口转发。

不在后台继续服务

iOS 将应用切到后台时监听停止。过早的请求收到 service-unavailable，而不是挂起。

不替你执行工具

服务器只返回工具调用；是否执行永远由客户端决定。

不悄悄回落云端

模型进不了内存时会明确告诉你。推理绝不会悄悄挪到托管端点。

不向外回传

没有遥测，没有分析 SDK。唯一的外发流量是你自己发起的模型下载。

不超出证据说话

模拟器截图会明确标注；真机的温度与内存验证另有文档说明。
