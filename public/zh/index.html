03 安装

从下载到模型驻留

两个版本都是同样的三步。需要说清楚的一点：侧载 IPA 必须用你自己的证书重签，而内存 entitlement 必须在这一步之后仍然存在。

01

选定版本

下载工作台或服务器的 IPA。两者都是面向重签工具的 ad-hoc 签名产物，都不是 App Store 安装包。

02

安装并重签

用 AltStore / AltServer、SideStore，或想在设备上直接签名就用 ForgeSign。确认内存 entitlement 还在——否则 iOS 会压低进程上限，大模型在加载时直接被杀。

03

载入模型

仓库不含权重。在设备上导入 GGUF 或下载 MLX 模型，然后让它驻留。LAS 里轮换一次 bearer key，再把客户端指向局域网地址。

entitlement 为什么关键。 com.apple.developer.kernel.increased-memory-limit 提高单进程内存上限，让数十亿 参数的权重和 KV 缓存能够驻留；com.apple.developer.kernel.extended-virtual-addressing 允许 MLX 与 llama.cpp 分配器做大块虚拟地址预留。重签工具可能会悄悄丢掉这两项。
04 开发者

把你的工具指向手机

两个版本都由 LocalAPIServer.swift 提供——工作台里可选开启，LAS 里始终开启。 bearer 鉴权的明文 HTTP，只面向你能掌控的网络。

一次一个示例

# 从局域网里的手机流式请求一次补全
$ curl -N http://192.168.1.8:11434/v1/chat/completions \
    -H "Authorization: Bearer $KEY" \
    -H 'Content-Type: application/json' \
    -d '{"model":"你的模型id","stream":true,
         "messages":[{"role":"user","content":"一句话解释 SSE。"}]}'
# 让 aider 指向手机
$ export OPENAI_API_BASE=http://192.168.1.8:11434/v1
$ export OPENAI_API_KEY=<应用里显示的 key>
$ aider --model openai/你的模型id
# 或者用同一个 key 走 Anthropic 方言
$ export ANTHROPIC_BASE_URL=http://192.168.1.8:11434
$ export ANTHROPIC_API_KEY=<同一个 key>
$ curl -s $ANTHROPIC_BASE_URL/v1/messages \
    -H "x-api-key: $ANTHROPIC_API_KEY" \
    -d '{"model":"你的模型id","max_tokens":512,
         "messages":[{"role":"user","content":"ping"}]}'

05 边界

  
它做什么、不做什么

  
把话说清楚，因为在这里信任就是产品本身。

  

    

      
只面向可信局域网

      
bearer 鉴权的明文 HTTP，为你能掌控的网络设计，不适合暴露到公网。不要做端口转发。

    

    

      
只在前台工作

      
iOS 把应用切到后台时监听停止。模型尚未驻留时到来的请求会收到 service-unavailable，
         而不是挂起。

    

    

      
不擅自执行

      
服务器只返回工具调用，不执行它们。是否执行永远由客户端决定；非法的工具名或参数会先被
         拒绝。

    

    

      
不悄悄回落云端

      
模型进不了内存时会明确告诉你。不会因为设备说了「不」，就把推理悄悄挪到托管端点。

    

    

      
联网行为显式

      
唯一的外发流量是你自己发起的模型下载。提示词、权重和输出都留在应用存储里。

    

    

      
可审计

      
MIT 源码，带 CI 校验、CodeQL、OpenSSF 评分卡、SPDX SBOM，以及每个版本的 SHA-256
         校验和与第三方声明。

    

  


  

    

      
      

        
只有你主动发起的：从 Hugging Face 下载模型，或在你自己局域网里可选开启的 Mac 配对通道。
           提示词、权重、历史和输出都留在应用存储里。没有遥测，也没有分析 SDK。

      

    

    

      
      

        
签名环节可以：ForgeSign 直接在设备上重签 IPA。AltStore 和 SideStore 则视你的证书而定，
           周期性刷新可能需要电脑或服务器。

      

    

    

      
      

        
设备内存装得下的任何 MLX 模型或 GGUF，同时受模型许可约束。应用会在下载前检查内存适配，
           某个家族不支持工具调用时会提前警告，而不是在会话中途失败。

      

    

    

      
      

        
目前没有。仓库是源码分发的正式地址，侧载构建出现在 Releases 下。该应用此前曾通过
           App Store 分发。
