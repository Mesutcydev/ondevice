开发者

你的 iPhone
就是服务器。

OnDevice LAS 以及 Max 和 Core 中的 API 服务器，可在局域网内响应标准请求。把 Cursor、脚本或智能体指向你的手机，模型始终保持私密。

# 占位符，并非真实值
curl -N http://PHONE-IP:11434/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -d '{"model":"MODEL-ID","stream":true,
       "messages":[{"role":"user","content":"Hello"}]}'
  • OpenAI/v1/models · /v1/chat/completions · /v1/responses
  • Anthropic/v1/messages
  • Ollama/api 下的模型、聊天和生成接口

面向可信网络的 Bearer 认证 HTTP。iOS 将应用切到后台时会停止；请勿做端口转发。 集成指南 ↗

侧载安装。

这些应用暂未上架 App Store。你需要自行安装 IPA，并用自己的 Apple ID 签名，大约五分钟。

在应用一览中选择应用，从 GitHub Releases 下载 IPA。应用不附带模型权重。

02

签名并安装

在 Mac 或 iPhone 上用签名工具打开 IPA，以下任一均可：

AltStore ↗SideStore ↗ForgeSign ↗
03

下载模型，离线使用

打开应用，下载适合你手机的模型并加载。然后打开飞行模式，继续使用。

保留内存权限

请确保签名工具保留 increased-memory-limit 和 extended-virtual-addressing 权限。否则 iOS 会限制应用内存，大模型会在加载时被终止。

如何在 iPhone 上离线运行大语言模型？

安装 OnDevice Core（iOS 27），通过 Wi-Fi 下载一次模型（例如 Qwen 3 4B）并加载。之后聊天完全无需联网，飞行模式下也可以。OnDevice Max 发布后用法相同。

OnDevice 应用在 App Store 上吗？

目前不在。它们以可侧载的 IPA 文件发布在 GitHub Releases 上，你可以用 AltStore、SideStore 或 ForgeSign 在自己的设备上签名安装。源代码以 MIT 许可公开。

Max 和 Core 有什么区别？

两者共享相同的设备端引擎和功能。Max 采用全新、更安静的界面，即将推出；Core 保留原版 Studio 界面，现已可用。OnDevice LAS 把 iPhone 变成本地 API 服务器，OnDevice Image Generation 用于生成图片。

支持哪些 iPhone？

OnDevice LAS 需要 iOS 18 或更高版本，OnDevice Image Generation 需要 iOS 26，OnDevice Core 和 Max 需要 iOS 27。模型越大需要的内存越多；模型库会在下载前检查模型是否适合你的设备。

我输入的内容会离开手机吗？

默认不会。推理在设备上运行，没有账号、分析或遥测。网络只用于你发起的模型下载，以及你主动开启的可选功能，例如联网访问、Apple Private Cloud Compute 或配对的 Mac。

能在不联网的 iPhone 上生成图像吗？

可以。OnDevice Image Generation 使用 MLX 和 Core ML 在本地运行 Stable Diffusion 1.5、2.1、SDXL 和 SDXL Turbo。OnDevice Max 和 Core 也内置图像工作室。

iPhone 能作为兼容 OpenAI 的 API 使用吗？

可以。OnDevice LAS 在局域网内以 Bearer 密钥保护，提供兼容 OpenAI、Anthropic 和 Ollama 的接口。它面向可信网络，iOS 将应用切到后台时会停止。

OnDevice 免费且开源吗？

是的。原创代码采用 MIT 许可，无需账号、无需订阅。模型权重需单独下载，并遵循各自的许可。
