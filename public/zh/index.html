如何在 iPhone 上离线运行大语言模型？

安装 Token AI（iOS 27+）或 OnDevice Local AI Studio（iOS 18+），再通过 Wi-Fi 下载兼容的本地模型。首次下载可试用体积更小的 Qwen3 0.6B。加载后，模型可以在飞行模式下回答问题。

OnDevice 应用在 App Store 上吗？

其中两款已上架。Token AI（原名 OnDevice Max）和 OnDevice Local AI Studio 已在 App Store 免费提供。OnDevice LAS 仅提供侧载版本，OnDevice Image Generation 仍在等待 App Store 上架。源代码继续以 MIT 许可公开。

Token AI 和 Local AI Studio 有什么区别？

Token AI（原名 OnDevice Max）是采用全新、更简洁界面的最新一体化工作室，需要 iOS 27。OnDevice Local AI Studio 保留原版 Studio 界面，支持 iOS 18 及更高版本。OnDevice LAS 把 iPhone 变成本地 API 服务器，OnDevice Image Generation 用于生成图片。

支持哪些 iPhone？

OnDevice Local AI Studio 和 OnDevice LAS 需要 iOS 18 或更高版本，OnDevice Image Generation 需要 iOS 26，Token AI 需要 iOS 27。模型越大需要的内存越多；模型库会在下载前检查模型是否适合你的设备。

我输入的内容会离开手机吗？

使用已下载模型进行本地聊天时，提示词在 iPhone 上处理。可选的网页工具和外部模型提供方可以接收你选择发送的内容。iCloud 同步和配对的 Mac 工具在启用时也会使用网络。

能在不联网的 iPhone 上生成图像吗？

可以。OnDevice Image Generation 使用 MLX 和 Core ML 在本地运行 Stable Diffusion 1.5、2.1、SDXL 和 SDXL Turbo。Token AI 和 OnDevice Local AI Studio 也内置图像生成。

iPhone 能作为兼容 OpenAI 的 API 使用吗？

可以。OnDevice LAS 在局域网内以 Bearer 密钥保护，提供兼容 OpenAI、Anthropic 和 Ollama 的接口。它面向可信网络，iOS 将应用切到后台时会停止。

OnDevice 免费且开源吗？

是的。原创代码采用 MIT 许可，无需账号、无需订阅。模型权重需单独下载，并遵循各自的许可。
